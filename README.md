# Silksong Checklist (local copy)

An local browser checklist based on the public community checklist at [checklistsilksong.com](https://checklistsilksong.com/).

## Run locally

Open `index.html` in Chrome or another browser. The app has no build step, dependencies, or required local server.

Checklist state saves automatically in this browser's local storage. Use **Export** to download a JSON backup and **Import** to restore it. Completion progress counts the 124 items in the main completion categories; the 30 fleas and 43 bosses are tracked separately, as on the source site.

The checklist data is bundled in `checklist-data.js`. Item and map artwork uses the original site's public image URLs, so images require an internet connection.
